# GitHub Issues archive

Before planning moved to [Linear](https://linear.app/regimen-works), this repo
tracked its work in GitHub Issues: 101 issues, `#2`–`#161`, all closed by
2026-09-11. GitHub Issues is now switched off (DN-62). That hides the issues
rather than deleting them, so **the links below stop working**; switching Issues
back on in the repo's Settings → Features brings them back.

This table is what keeps an old `#N` traceable. Use it when a commit message or
PR body from before 2026-09-11 cites one.

- **A `#N` that is not listed here is a pull request**, not an issue. GitHub
  numbers issues and PRs from the same counter, so the later `(#163)`-style
  suffixes on commit subjects are PRs: `https://github.com/Patch-1331/regimen-works/pull/N`.
- **A `#N` and a `DN-N` with the same number are unrelated.** GitHub `#17` is
  the program editor; `DN-17` is the rest-day makeup rule. The **Linear** column
  gives the real counterpart, where one exists.
- **Linear** is the Linear issue (or project, for an epic) that carried the same
  work, matched by title. A dash means the work shipped before Linear existed
  and was never copied across. That is mostly the four shipped epics and their
  stories: `#2` progressions, `#11` stats, `#30` interval timer, `#63`
  warm-up / cool-down.
